# KeoBong Pro

KeoBong Pro is a mobile-first management platform for Vietnamese amateur football teams that coordinate through Zalo groups.

## Foundation

- Next.js App Router with TypeScript.
- Tailwind CSS v4 token setup.
- shadcn/ui-style component ownership under `src/components/ui`.
- Mobile-first app shell with team-scoped routes.
- Service boundaries for future Supabase, n8n, and Zalo Mini App integration.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run lint
```

The default local route redirects to `/teams/demo-fc`.
